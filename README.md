# 글벗 (Geulbeot) — 스스로 성장하는 글쓰기 웹앱

로컬에서 동작하는 한국어 글쓰기 향상 웹앱입니다. Claude API를 사용해 세 가지 방식으로 글쓰기를 돕습니다.

## 기능

### 🖋️ 매일 글쓰기
- 그날의 느낌·생각을 자유 주제로 작성
- 글 상단에 **오늘의 질문** — 📚 나의 서재에 등록한 작품에서 매일 하나를 무작위로 (🎲 로 다른 질문)
- AI 분석: **코멘트(장점·아쉬운 점)** · **새로운 질문** · **바꿔보면 좋을 단어 추천**
- 오른쪽 **오늘의 단어** — AI가 하루 한 단어를 제시하고, 그 단어로 질문을 주고받음
- 마라톤처럼 **15 · 30 · 50 · 100일** 등 마일스톤과 연속 기록으로 동기부여

### 📖 스토리 쓰기
- 주제를 정해 하나의 이야기를 이어서 완성
- 전문 작가로서의 평가·피드백 (기본 모드)
- 창작 과정 질의응답

### 💬 독서토론
- 책 제목 / 읽은 부분 텍스트 / **사진(비전 인식)** 으로 시작
- 소크라테스식 대화로 비판적 사고·새로운 사고·요약 능력·자기 표현력을 기름
- 질문 유도, 작성한 문장에 대한 피드백

### ✍️ 필사
- 필사할 책의 기본 정보(제목 · 저자 · 출판사)를 등록
- 책을 보며 마음에 닿는 대목을 직접 옮겨 적고, 쪽수와 함께 저장
- 필사하며 떠오른 **💭 내 생각**을 바로 옆에 덧붙이고, 나중에 다시 읽으며 생각을 계속 더할 수 있음
- 대목 · 생각 수정/삭제, 책별 필사 노트를 텍스트로 내려받기
- 필사한 날 · 연속 기록 · 필사한 대목 수
- **🔍 문장 해설**: AI가 대목의 문체 · 눈여겨볼 표현 · 따라 써보기 과제를 짚고, 내 생각에도 한마디

### 📚 나의 서재
- 좋아하는 작품(제목 · 저자 · 메모)을 등록하면 AI가 글쓰기 질문 8개를 만들어 둠
- 매일 글쓰기의 '오늘의 질문'은 이 질문들 중에서 나옴 (최근 30일 내 나온 질문은 피함)

## 설치 및 실행

1. 의존성 설치
   ```bash
   npm install
   ```

2. 환경변수 설정 — `.env.example` 을 복사해 `.env` 를 만들고 API 키를 넣으세요.
   ```bash
   cp .env.example .env
   ```
   `.env` 안의 `ANTHROPIC_API_KEY` 에 [Anthropic Console](https://console.anthropic.com) 에서 발급받은 키를 붙여넣습니다.

3. 실행
   ```bash
   npm start
   ```
   브라우저에서 `http://localhost:5174` 접속.

## 백그라운드 자동 실행 (Windows)

Windows 작업 스케줄러에 **`Geulbeot Server`** 작업이 등록되어 있습니다.

- **로그인할 때 자동 시작** (15초 지연), 콘솔 창 없이 백그라운드 실행
- **10분마다 감시** — 서버가 꺼져 있으면 자동으로 다시 띄움
- 이미 5174 포트가 열려 있으면 실행을 건너뛰므로 **중복 실행 없음**
- 실행 로그는 `logs/server.log` 에 누적

| 작업 | 명령 |
|------|------|
| 지금 시작 | `schtasks /Run /TN "Geulbeot Server"` |
| 지금 중지 | `scripts\stop-server.cmd` (※ 10분 내 감시 트리거가 다시 켬) |
| 자동 실행 끄기 | `schtasks /Change /TN "Geulbeot Server" /DISABLE` |
| 자동 실행 켜기 | `schtasks /Change /TN "Geulbeot Server" /ENABLE` |
| 상태 확인 | `schtasks /Query /TN "Geulbeot Server"` |
| 등록 삭제 | `schtasks /Delete /TN "Geulbeot Server" /F` |

관련 파일: `scripts/start-hidden.vbs` (창 없이 실행하는 래퍼) → `scripts/start-server.cmd` (실제 실행·로그 기록) / `scripts/stop-server.cmd` (종료)

> 이 작업은 **로그인한 사용자 계정**으로 실행됩니다. 로그인 없이 부팅 직후부터 띄우려면 관리자 권한으로 Windows 서비스(NSSM 등) 등록이 필요합니다.

## 설정 (.env)

| 변수 | 설명 | 기본값 |
|------|------|--------|
| `ANTHROPIC_API_KEY` | Claude API 키 (필수) | — |
| `CLAUDE_MODEL` | 사용 모델. 비용 절감 시 `claude-sonnet-5` | `claude-opus-5` |
| `CLAUDE_EFFORT` | 사고 깊이 `low`~`max` | `medium` |
| `PORT` | 서버 포트 | `5174` |

## 영어 번역 캐시 (번역 메모리)

`🌐 영어로 보기` 로 한 번 번역한 문단은 `data/translations.json` 에 저장되어 **다시 번역할 때 API를 호출하지 않습니다.**

- 저장 단위는 **문단**(빈 줄 기준). 글을 이어 썼다면 **새로 추가된 문단만** API를 호출합니다.
- 원문이 같으면 재사용, 문단을 고치면 그 문단만 다시 번역합니다. (줄끝 공백·줄바꿈 형식 차이는 무시)
- 새 문단을 번역할 때는 바로 앞 문단 2개를 *참고용 문맥*으로 함께 보내, 주어가 생략된 한국어의 인칭·시제가 흔들리지 않게 합니다. (문맥은 캐시 키에 포함되지 않아 재사용에 영향을 주지 않습니다)
- 번역 패널 우측에 `저장된 번역 · API 호출 없음` / `문단 N개 재사용` 표시가 뜹니다.
- 저장 항목이 5000개를 넘으면 오래 안 쓴 것부터 정리됩니다. 캐시를 비우려면 `data/translations.json` 을 삭제하세요.

## 데이터 저장

모든 글과 대화는 `data/` 폴더에 JSON 파일로 로컬 저장됩니다. (`daily.json`, `story.json`, `book.json`, `translations.json`)
API 키와 `data/` 는 `.gitignore` 로 제외됩니다.

## 기술 스택

- 백엔드: Node.js + Express, `@anthropic-ai/sdk`
- 프론트: 바닐라 JS (의존성 없음)
- 저장: 로컬 JSON 파일

> API 키는 서버의 `.env` 에만 있으며 브라우저에 노출되지 않습니다. 모든 Claude 호출은 서버가 대신 수행합니다.
